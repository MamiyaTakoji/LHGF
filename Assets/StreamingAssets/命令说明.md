这个文档用于说明每个命令使用的参数

命令名称：`Speak`

| 参数名称           | 描述                                                         | 默认值      |
| ------------------ | ------------------------------------------------------------ | ----------- |
| **Content**        | 对话内容文本（必需）                                         | 无          |
| **TextType**       | 文本渲染类型。取值：`"TexDraw"`（LaTeX 公式和文本渲染）、`"TMP"`（TextMeshPro 普通文本）。 | `"TexDraw"` |
| **Skip**           | 是否跳过该段对话的显示动画                                   | `false`     |
| **SpeakerName**    | 说话者名称。若不提供则通过`CharacterID`从角色数据中获取。    | 空字符串    |
| **CharacterID**    | 角色数据的ID，使用时请保证这个ID已经被添加                   | 无          |
| **DepartmentName** | 说话者所属部门/组织。若不提供则通过`CharacterID`从角色数据中获取。 | 空字符串    |
| **CVPath**         | 角色语音资源路径                                             | 无          |

命令名称：`LongSpeak`

| 键名         | 描述                                                         | 默认值      |
| ------------ | ------------------------------------------------------------ | ----------- |
| **Content**  | 长对话内容（必需）。可为纯文本、LaTeX 文本或图片资源路径。   | 无          |
| **TextType** | 内容渲染类型。取值：`"TexDraw"`（LaTeX 公式渲染）、`"TMP"`（TextMeshPro 普通文本）、`"Image"`（显示图片）。 | `"TexDraw"` |
| **Continue** | 是否延续上一组长对话。值为 `"0"` 表示不延续（开启新组），非 `"0"` 表示继续添加至当前组。 | `"1"`       |
| **Skip**     | 是否跳过该段对话的显示动画。值为 `"0"` 表示不可跳过，非 `"0"` 表示可跳过。 | `"0"`       |
| **Rate**     | 图片占长对话框的比例。仅当 `TextType` 为 `"Image"` 时有效。  | `"0"`       |
| **CVPath**   | 角色语音资源路径                                             | 无          |

命令名称：`Choice`

| 键名         | 描述                                                     | 默认值 |
| ------------ | -------------------------------------------------------- | ------ |
| **NextId**   | 选项对应的后续章节ID列表，多个ID之间用 `%%` 分隔（必需） | 无     |
| **TextType** | 选项文本的渲染类型列表，多个类型之间用 `%%` 分隔（必需） | 无     |
| **Content**  | 选项的显示文本列表，多个文本之间用 `%%` 分隔（必需）     | 无     |

命令名称：`AddCharacter`,`ImageCharacterAnimation`

| 键名                           | 描述                                                         | 默认值             |
| ------------------------------ | ------------------------------------------------------------ | ------------------ |
| **From**                       | 角色标识符（必需）。当 `CharacterID` 未提供时使用此键指定角色，用于从角色数据中获取立绘资源路径及默认立绘名称。 | 无                 |
| **CharacterID**                | 角色标识符（可选）。                                         | 无                 |
| **ImageCharacterIllustration** | 立绘资源文件名（可选）。若缺省，则使用 `"Portrait-Normall"` 作为默认立绘。 | 从角色数据动态获取 |
| **DOTweenAnimation**           | DOTween 动画名称（可选），用于控制角色立绘的入场/动作动画。  | `"SetAt"`          |
| **ConnectMethod**              | 动画序列拼接方式（可选），取值 `"Append"`（顺序播放）或 `"Join"`（并行播放）。 | `"Append"`         |

命令名称：`ChangeImageBackground`

| 键名                 | 描述                                                         | 默认值            |
| -------------------- | ------------------------------------------------------------ | ----------------- |
| **BgImage**          | 背景图片资源路径（必需）。该路径会与 `Utils.ResoucePaths.BackgroundPath` 组合成完整加载路径，用于设置背景图。 | 无                |
| **DOTweenAnimation** | DOTween 动画名称（可选）。对应 `Utils.DOTweenLuaCommandDic` 中的键，用于控制背景切换动画效果。 | `"BgChange_Fade"` |
| **ConnectMethod**    | 动画序列拼接方式（可选）。仅用于 `Next` 方法中的多动画组合，取值 `"Append"`（顺序播放）或 `"Join"`（并行播放）。 | `"Append"`        |

命令名称：`SetBgm`

| 键名          | 描述                                                         | 默认值 |
| ------------- | ------------------------------------------------------------ | ------ |
| **BgmName**   | 背景音乐资源文件名（必需）。若值为 `"STOPBGM"` 则停止当前背景音乐；否则会与 `Utils.ResoucePaths.BgmPath` 组合成完整路径进行加载。缺省时会输出警告，且后续操作可能异常。 | 无     |
| **IsLoopStr** | 是否循环播放，`"1"` 表示循环，`"0"` 表示不循环。             | `"1"`  |

命令名称：`VideoAnimation`

| 键名          | 描述                                                      | 默认值                            |
| ------------- | --------------------------------------------------------- | --------------------------------- |
| **VideoName** | 视频动画资源文件名（必需）。                              | 无                                |
| **IsLoop**    | 是否循环播放。值为 `"1"` 表示循环，`"0"` 表示不循环。     | `"0"`（不循环）                   |
| **Size**      | 视频动画的缩放比例，相对于原始尺寸。                      | `"1"`                             |
| **Rotation**  | 视频动画的旋转角度（单位：度）。                          | `"0"`                             |
| **PosX**      | 视频动画在屏幕中的水平锚点位置（归一化坐标，0~1）。       | `"0.5"`                           |
| **PosY**      | 视频动画在屏幕中的垂直锚点位置（归一化坐标，0~1）。       | `"0.5"`                           |
| **Finish**    | 停止播放指定视频动画。值为 `"1"` 时强制结束并隐藏该动画。 | 无（仅当存在且值为 `"1"` 时生效） |

命令名称：`CameraAnimation`

| 键名                 | 描述                                                         | 默认值     |
| -------------------- | ------------------------------------------------------------ | ---------- |
| **DOTweenAnimation** | DOTween 动画名称（可选）。                                   | `"SetAt"`  |
| **ConnectMethod**    | 动画序列拼接方式（可选）。取值 `"Append"`（顺序播放）或 `"Join"`（并行播放）。 | `"Append"` |

命令名称：`EffectiveSound`

| 键名                   | 描述                                                   | 默认值 |
| ---------------------- | ------------------------------------------------------ | ------ |
| **EffectiveSoundPath** | 音效资源文件名（必需）。若缺失该键，则不执行任何操作。 | 无     |

命令名称：`Blackboard`

| 键名                | 描述                                                         | 默认值                      |
| ------------------- | ------------------------------------------------------------ | --------------------------- |
| **Content**         | 黑板内容（必需）。                                           | 无                          |
| **TextType**        | 内容渲染类型。取值：`"TexDraw"`（LaTeX 公式渲染）、`"TMP"`（TextMeshPro 普通文本）、`"Image"`（显示图片）。 | `"TexDraw"`（无参考）或继承 |
| **Continue**        | 是否延续上一黑板数据组。`"1"` 表示追加至当前组末尾，`"0"` 表示开启新组。 | `"1"`（true）               |
| **Skip**            | 是否跳过该段内容的显示动画。                                 | `"0"`（false）              |
| **Rate**            | 图片显示速率（可选）。仅当 `TextType` 为 `"Image"` 时有效，控制图片动画速度。 | `"0"`（解析为 `0.0f`）      |
| **FontSize**        | 文本字体大小。                                               | `"36"` 或继承               |
| **SizeX**           | 黑板区域的宽度比例。                                         | `"0.6"`                     |
| **SizeY**           | 黑板区域的高度比例。                                         | `"0.6"`                     |
| **PosInfo**         | 黑板位置预设。取值 `"UpperLeft"`、`"UpperCenter"`、`"UpperRight"` | 无                          |
| **PosX**            | 黑板水平锚点位置（归一化坐标，0~1）。仅当未使用 `PosInfo` 预设时生效。 | `"0.4"`                     |
| **PosY**            | 黑板垂直锚点位置（归一化坐标，0~1）。仅当未使用 `PosInfo` 预设时生效。 | `"0.4"`                     |
| **BlackboardState** | 黑板显隐状态。`"1"` 表示显示黑板并更新内容，`"0"`表示隐藏黑板。 | `"1"`                       |
