4. `CloesButton`（`Close` 拼错，3 处）——未提；

6. `PlayeBGM`、`ImageBgHight`、`Commnad`、`destory`——未提。

`Talker`（聊天对象，词本身存在）、`datas`（`Data` 的复数误用，134 处）、`Canva`（已单列）、
