## 五、给 GitHub 备份的建议

删除只能省 5 MB，对 1.48 GB 的仓库没有意义。想让仓库变小，只有三条路：

1. **不动素材，直接推**：1.5 GB 在 GitHub 的软限制（1 GB 警告）之上，但能推，只是慢；
   单文件最大 49 MB（`wave.wav`），没有触发 100 MB 硬限制。
2. **仓库只放代码**：`StreamingAssets/HGF/Texture2D`、`Audio` 写进 `.gitignore`，
   素材另存网盘/移动硬盘。仓库降到约 150 MB。
3. **素材走 Git LFS**：免费额度 1 GB 存储，这个项目会超额，需要付费。

推荐 2：代码和素材分开备份，各自都能独立恢复。
